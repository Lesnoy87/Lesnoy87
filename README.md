# Lesnoy87

Small mods for **7 Days to Die** — fog, lighting, atmosphere, and moon-driven gameplay.
Made and tested by hand; source published for every release.

Русский / English.

## Mods

| Mod | What it does | Links |
|---|---|---|
| **Silent Fog** | Dense outdoor fog that stays out of houses, trader safe zones and closed vehicles. Host-side menu, settings synced to all players. | [Nexus](https://www.nexusmods.com/7daystodie/mods/13963) · [Source](https://github.com/Lesnoy87/silent-fog-client) |
| **DifRUST** | Rust-style nights: gradual dusk, full darkness from 22:00 to 04:00, gradual dawn. Weather and clouds shape moonlight, eye adaptation, NVG/flashlight relief, biome night tint matching Silent Fog, host lock. In-game menu (English / Russian). | [Nexus](https://www.nexusmods.com/7daystodie/mods/13981) · [Source](https://github.com/Lesnoy87/difrust-client) |
| **LunarEvents** | Moon and day phases that change gameplay: 8 night phases, rare blessed and cursed moons, daytime trade/craft/loot/travel modifiers, Wild and Fatal nights. | [Download](https://github.com/Lesnoy87/LunarEvents/releases/latest) · [Source](https://github.com/Lesnoy87/LunarEvents) |

## How I work

- Every build is tested in game before release; screenshots and testing are done by hand.
- Source code ships with every mod. Licenses differ: **Silent Fog 1.15.0+** is All Rights Reserved (older versions MIT); **DifRUST 1.4.2+** is All Rights Reserved (1.4.1 and earlier MIT); **Lunar Events 0.3.1+** is All Rights Reserved (0.3.0 and earlier MIT). See each repository's `LICENSE`.
- AI assistance is used for code and documentation, and it is disclosed on every mod page.
- No gameplay changes: visuals only, unless a mod says otherwise.
